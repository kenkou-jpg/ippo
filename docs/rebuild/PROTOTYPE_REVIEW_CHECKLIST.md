## 確認項目

### 1. 体質改善実験プラットフォームに見えるか
- [ ] Homeを開いた瞬間に「記録・日記アプリ」ではなく「実験ノート」だと感じるか
- [ ] 気づきカードの文章が、記録の羅列ではなく発見として響くか
- [ ] Experiment画面が「我慢・禁止」ではなく「小さな挑戦」に見えるか

### 2. 毎日開きたくなるか
- [ ] Homeの気づきカード・次につなげるカードに「明日も見たい」と思わせる要素があるか
- [ ] 進行中の実験（Day 5/14）の見せ方に、続けたくなる手応えがあるか

### 3. 記録が億劫に見えないか
- [ ] Record画面を開いてから記録完了まで、直感的に10秒程度で終えられそうか
- [ ] 3カード固定・チップ選択中心の構成が、入力の負担を感じさせないか
- [ ] 行動タグが「制限リスト」ではなく「観察対象」に見えるか

### 4. Homeの情報量は適切か
- [ ] 6ブロック（記録／気づき／実験／結果／次につなげる＋ヘッダー）で情報過多に感じないか
- [ ] スクロール量は許容範囲か（縦一列で疲れずに見渡せるか）

### 5. Experiment導線が自然か
- [ ] Insightsの気づき→Experimentのおすすめ実験、という流れに違和感がないか
- [ ] 実験ライブラリのカードが軽く試せそうに見えるか

### 6. Premium/Proの価値が伝わるか
- [ ] Premium＝「理解を深める」、Pro＝「改善実験を進める」という役割の違いが文章から伝わるか
- [ ] Insights内のロック表現（ぼかし＋理由）が押し付けがましくなく、自然な誘導に感じるか
- [ ] 比較表ではなく文章中心の見せ方が、機能列挙より魅力的に感じるか
