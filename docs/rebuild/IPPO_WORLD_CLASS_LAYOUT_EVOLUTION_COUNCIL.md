# Executive Summary

PR-LAYOUT-01により、Prototypeは「機能不全」の水準を脱した（時系列の整合・AIコピーの脱断定・オンボーディング・安心感訴求はすべて解消済み）。本Councilが問うのは一段上の基準、「世界トップクラスのプロダクト体験になっているか」である。

比較研究の結果、IPPOの情報密度規律（Home最大6ブロック）は、慢性疾患・易疲労ユーザー向けに設計されたVisibleの「低刺激デザイン」原則と一致しており、**これはIPPOの本物の強みであり、今後も薄めてはならない**。

一方で4つの明確なギャップを発見した。

1. **Homeに「これだけ見ればいい」という単一の圧倒的な指標がない**。Zeroの巨大な進捗リング、Clueの周期日表示のような、視線が自然に着地する主役がHeroに存在せず、4要素が並列している。
2. **「気づき」カードに相関の強さを視覚的に示す仕組みがない**。BearableやExistはテキストだけでなく、強度メーター・矢印・色の濃淡で相関の確からしさを直感的に伝える。IPPOは現状テキストの信頼度タグのみ。
3. **実験完了の瞬間に「お祝い」の演出がない**。Zero・Habitifyはマイルストーン到達を一瞬の特別な画面演出で祝う（過度なゲーミフィケーションではなく、控えめな敬意の表現として）。IPPOはインラインテキスト「お疲れさまでした」のみ。
4. **記録の継続を視覚化する仕組みがHomeにない**。Clueのタイムラインストリップに相当する「直近7日の継続」を示す軽量な要素が欠けている。

これらはいずれもレイアウト・コピー・ダミーデータのみで対応可能であり、コード禁止・Business Logic禁止の制約内で実現できる。**Final Verdict: GO**（PR-LAYOUT-02候補として追加、実装フェーズを妨げるものではない）。

# Home Review

**世界トップとの比較で不足しているもの**:
Heroは「挨拶／Day数／実験名／進捗バー／今日の目的」の5要素が縦に並び、情報としては正確だが、視線が「まずここを見ればいい」と迷わず着地する主役がない。Zero（断食タイマーの巨大な円環）、Clue（周期日を表す大きな数字とリング）は、いずれも1つの視覚要素にデザインの重心を極端に集中させている。IPPOのHero内の要素は重要度がほぼ均等に描かれており、Design Systemのタイポグラフィ階層（Day数を44px→2.75rem）はあるものの、周囲の要素（進捗バー・挨拶文・目的欄）が同程度の視覚的主張を持ってしまい、相対的な「主役感」が薄まっている。

**削るべきもの**:
Hero最上部の挨拶文（「おはようございます、あかりさん」）は、情報価値が低いにもかかわらず最初に読まれる位置を占めている。世界トップのアプリはこの種の挨拶を小さく添え書き程度に扱うか、Eyebrow（"EXPERIMENT LOG"）と統合して1行に収める傾向がある。

**追加すべきもの**:
Clueのタイムラインストリップに着想を得た、直近7日間の「記録した/していない」を示す小さなドット列。Hero下部か記録帯の近くに配置し、「続いている」感覚を視覚化する。新規のごく軽量なコンポーネントで、レイアウトのみで実現可能。

# Record Review

前回監査で「10秒〜30秒で記録できる」ことは確認済み（最短4タップ）。世界最高水準（Daylioの2タップ完了）と比較するとタップ数はやや多いが、これは単純比較として不適切である。Daylioは気分の単一軸ログであるのに対し、IPPO・Bearableはいずれも複数軸（気分・睡眠・肌・行動タグ）の観察を目的としており、Bearableも同程度のタップ数を許容している。**結論: 現状のタップ数は世界水準として妥当**。

改善余地: 気分ピッカーの絵文字5段階は、Daylioと似た構成だが、Daylioはタップ領域と表情の差分がより大きく、瞬間的な選択がしやすい。IPPOの絵文字ボタン（現状20px相当）をわずかに拡大し、選択時の視覚変化（現状は背景色のみ）にスケールアニメーションを加えることで、瞬間的な選びやすさが向上する（レイアウトのみで対応可）。

# Insights Review

PR-LAYOUT-01により「分析画面ではなく気づき」への改善は大きく進んだ（問いかけ形式のリード文、ハイライトカードの一貫性）。

**世界トップとの差**: BearableとExistは、相関の「強さ」をテキストだけでなく視覚的（バーの長さ、ドットの数、色の濃淡）に示す。IPPOは現状「7件のデータから検出」というテキストの信頼度タグのみで、視覚的な強度表現を持たない。これは「科学的根拠」を伝える力においてIPPOがまだ一歩劣る点である。

**追加提案**: 気づきカード内に、3〜5段階の小さな確信度メーター（ドット表現、既存のDesign Systemの色トークンで実現可能）を追加し、テキストと視覚の両方で確からしさを伝える。

---

# Experiment Review

前回監査で指摘した「CTAの重みが弱い」「ロックカードが不透明度低下のみ」は未解消のまま。

**世界トップとの比較**: Zeroは進行中の断食を、大きな円環と色の変化で「今、この段階にいる」ことを常に強く主張し続ける。IPPOの進行中実験カードのリングは相対的に小さく、Home上での存在感が控えめ。これは情報密度規律（Home最大6ブロック）とのトレードオフであるため、Home全体のバランスを崩さない範囲での調整に留めるべき（優先度: 中）。

「試してみたい」という動機付けについては、PR-LAYOUT-01で仮説文・観察対象・「いつでもやめられます」を追加したことで大きく改善している。残る課題はCTAの視覚的重みのみ。

---

# Premium Review

PR-LAYOUT-01で「あとで」導線を追加済み。ぼかし表現によるロック手法自体はFlo/Oviaと同じ業界標準的アプローチであり、方向性に問題はない。

**将来の改善余地（今回のスコープ外）**: 世界トップのアプリは、ユーザーが実際に触れようとした機能に応じてロック画面の文言を変える（コンテキスト連動）。IPPOは現状すべて同じ汎用モーダルが開く。これはPhase2以降、実データ接続後に取り組むべき課題であり、レイアウトのみでの対応範囲を超える。

# Navigation Review

5タブ構成・Record位置・アイコン配置に迷う要素はない。中央から離れたInsightsタブがやや親指から遠い位置になるが、これは5タブレイアウトにおける一般的な制約であり、業界標準の範囲内。**現状維持を推奨、変更提案なし**。

# Emotion Design Review

初回〜30日の感情曲線は、PR-LAYOUT-01のDay状態システムにより大枠が実現された。

**世界トップとの比較で追加すべきもの**: 実験完了（Day14/Day30）の瞬間に、専用の「お祝い」演出が現状存在しない（インラインテキスト「今日で完了・お疲れさまでした」のみ）。Zero・Habitifyはマイルストーン到達時に、画面全体を使った一瞬の演出を用意している（ただしバッジ乱発のような過度なゲーミフィケーションではなく、静かな敬意の表現に留めている点がIPPOのトーン原則と両立可能）。

IPPOのトーン（「臨床的すぎない、子供っぽすぎない」）を維持しながら実現するなら、実験完了日にHome上部へ一時的な専用バナー（「乳製品断ち、2週間お疲れさまでした」という単発の全幅カード、通常のHero/カードとは異なる控えめな金色のグラデーション）を追加することを推奨する。

# Prototype Improvement Roadmap

**Critical**（世界水準に届くために必須）: なし。IPPOは既に「機能する」水準にあり、以下はすべて磨き込みの範疇。

**High**:
- Homeの主役指標を強化する（Heroの視覚的重心を進捗/Day数へさらに集中させ、挨拶文を縮小する）
- 気づきカードに確信度メーター（視覚表現）を追加する
- 実験完了時の専用マイルストーン演出を追加する

**Medium**:
- 直近7日の継続ストリップをHomeに追加する
- 気分ピッカーの絵文字を拡大し、選択時のスケールアニメーションを追加する
- 進行中実験のプログレスリングをHome上でもう少し大きく見せる

**Low**:
- Premiumロック画面のコンテキスト連動文言化（実データ接続が前提のため今は不可）
- Record入力領域のタップフィードバック強化

# PR-LAYOUT-02候補

Critical項目はないため、Highのみを次PRの候補とする。

1. Homeの主役指標強化（Hero内の視覚的重心の再配分、挨拶文の縮小）
2. 気づきカードへの確信度メーター（視覚表現）追加
3. 実験完了時の専用マイルストーン演出追加

Medium項目（継続ストリップ、気分ピッカー強化、進行中実験リングの拡大）は、PR-LAYOUT-02のスコープに含めるかFounderが判断する。Low項目は本実装（実データ接続）以降に回す。

# Final Verdict

# GO

**理由**: 発見した差分はすべてHigh〜Low水準の磨き込みであり、Critical（世界水準に届くために必須）に分類される項目は存在しない。IPPOの情報密度規律・Record所要時間・ロック表現・ナビゲーション構造は、いずれも世界トップクラスのアプリと同水準かそれ以上（情報密度規律はVisibleの低刺激設計原則と一致する明確な強み）であることを確認した。PR-LAYOUT-02として上記Highの3項目に取り組むかはFounderの任意判断であり、[IPPO_REBUILD_INTEGRATION_COUNCIL.md](IPPO_REBUILD_INTEGRATION_COUNCIL.md)のMigration Roadmap Phase1（実データ接続）へ進むことを妨げるものではない。
