## 実装中に発見・修正した追加バグ

検証中、以前の`modal-backdrop`と同型のCSS詳細度バグを2箇所で新たに発見した。`.confidence-tag`と`.card-cta`がそれぞれ独自の`display`宣言を持っており、`[hidden]`属性を上書きしてしまうため、Day0で本来非表示のはずの「くわしく見る →」ボタンと空の信頼度タグが表示され続けていた。個別に`[hidden]`を上書きするのではなく、`[hidden] { display: none !important; }`というグローバルルールを追加し、同種のバグが今後別の要素で再発することを構造的に防いだ。
